# Mon Entreprise — Site de présentation

Petite application web statique (HTML, CSS, JavaScript) qui présente une entreprise : services, à propos, équipe et contact.

## Utilisation

Ouvrez simplement `index.html` dans un navigateur. Aucune installation nécessaire.

## Personnalisation

- Textes et contenu : `index.html`
- Couleurs et mise en page : `style.css` (variables en haut du fichier)
- Comportements (menu mobile, animations, formulaire) : `script.js`

## Publication avec GitHub Pages

1. Poussez le dépôt sur GitHub.
2. Dans **Settings → Pages**, choisissez la branche `main` et le dossier `/ (root)`.
3. Le site sera disponible à `https://<utilisateur>.github.io/<depot>/`.

> Le formulaire de contact ne fait que valider les champs : il n'envoie pas de message. Utilisez un service comme Formspree pour un envoi réel.
